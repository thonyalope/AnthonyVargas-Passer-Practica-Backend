Este repositorio contiene la solución a la **Prueba Técnica Backend** solicitada por Passer para la práctica profesional supervisada. La prueba consistió en desarrollar una API RESTful para el manejo de transacciones, cumpliendo con buenas prácticas de desarrollo, estructura escalable y pruebas de endpoints.

---

## 📋 Requisitos Técnicos
- Node.js 18+
- Postman
- Git
